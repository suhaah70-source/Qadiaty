# إعداد تشغيل المول الرقمي

## Android للتطوير

يحتاج التطبيق إذن الإنترنت في `android/app/src/main/AndroidManifest.xml`، وتمت إضافته. يسمح ملف Debug manifest باتصال HTTP المحلي فقط أثناء التطوير؛ نسخة Release لا تفعّل cleartext.

شغّل الخادم أولًا من مجلد المشروع:

```powershell
cd C:\Users\PC\OneDrive\Desktop\mercato_super\mercto
.\.venv\Scripts\Activate.ps1
python run.py
```

ثم شغّل تطبيق Flutter من مجلد المشروع في نافذة ثانية:

```powershell
flutter pub get
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8001/api/v1
```

العنوان `10.0.2.2` يربط محاكي Android بالخادم على الكمبيوتر. للهاتف الحقيقي استخدم IP الكمبيوتر على الشبكة نفسها، مثل:

```powershell
flutter run --dart-define=API_BASE_URL=http://192.168.1.20:8001/api/v1
```

اسمح بالاتصال على المنفذ 8001 في الشبكة المحلية إن منع جدار الحماية ذلك. لا تستخدم HTTP أو منفذًا مكشوفًا للإنترنت في الإنتاج؛ استخدم HTTPS.

## رمز OTP

في التطوير، الرمز الافتراضي هو `123456`، ويظهر في سجل الخادم. بعد إدخال الرقم الليبي، أرسل الرمز ثم أكّد الدخول. يوقف الخادم إرسال الرموز عندما تكون البيئة غير تطويرية إلى أن يُربط مزود SMS فعلي.

## مدير المنصة

انسخ `backend/.env.example` إلى `backend/.env`، ثم غيّر `ADMIN_PHONE` إلى رقم الإدارة. سجّل ذلك الرقم من شاشة إنشاء حساب وأكّد OTP، وسيُعطى الحساب دور مدير المنصة. غيّر `JWT_SECRET` و`OTP_SECRET` إلى قيم عشوائية طويلة قبل مشاركة بيئة التطوير.

## iOS

يتصل iOS Simulator عادة بخادم الكمبيوتر عبر `http://localhost:8001/api/v1`. بناء التطبيق وتوقيعه يتطلب macOS وXcode. للإطلاق استخدم عنوان HTTPS صالحًا ولا توسّع استثناءات ATS لاتصالات HTTP العامة.

## الإنتاج

- اربط مزود SMS يغطي ليبيا وأوقف الرمز الثابت.
- استخدم PostgreSQL بتعيين `DATABASE_URL` إلى رابط اتصال PostgreSQL.
- استخدم HTTPS وأسرارًا مستقلة عن مستودع الشيفرة.
- اربط تخزينًا سحابيًا للصور وسياسة نسخ احتياطي ومراقبة.
